# Personal Expense Tracker

## About the Project

This is a console-based Personal Expense Tracker developed in Python. The project helps users keep track of their daily expenses by allowing them to add, view, search, update, and delete expense records. All data is stored in a CSV file so that it is available even after the program is closed.

This project was created as part of my Python Programming course to practice Object-Oriented Programming (OOP), file handling, and exception handling.



## Features

- Add a new expense
- View all saved expenses
- Search expenses by ID
- Update existing expenses
- Delete expenses
- View total spending
- View category-wise expense summary
- Automatically generate unique IDs
- Automatically use today's date if no date is entered
- Save and load data using a CSV file
- Validate user input to prevent errors



## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- CSV File Handling
- Exception Handling
- Datetime Module

2. Open the project folder in VS Code.

3. Run the program:

bash
